GND Archive Qualification

GND Archive Qualification is a personal tool for saving and restoring files used by the owner's cloud agents. It uses Google Drive for ordinary files, folders, archive snapshots and checkpoints. An agent can save its work, download a saved archive into a later cloud workspace, and verify that the restored files match.

The current integration uses Google-managed agent execution, the Google Drive API and a private OAuth credential vault. Initial account authorization happens through Google's normal consent screen. The cloud runtime can then access authorized files without a laptop acting as a file server.

What access it requests

The app requests your email identity and the limited drive.file permission. That permission lets it work with files created by the app or explicitly opened or selected for the app. It does not authorize access to every existing file in your Drive. A shared parent folder does not automatically give the app access to every file inside it.

How agents use the files

The owner chooses the jobs and data. Jobs may create, read, change, rename, download or delete authorized files and folders. Some workflows use ZIP archives; others use ordinary individual files. File names, metadata, selected content or job outputs may be sent to an AI model when needed for the requested task. Additional AI providers are used only when the owner requests or authorizes that workflow.

This is a personal experimental integration, not a public file-hosting service. Read the privacy notice for data flows and controls and the use terms for operating limits.
